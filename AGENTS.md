# Instructions agents

Ce projet utilise `CLAUDE.md` comme source unique des instructions agents (partagée avec Codex).

Point le plus important, à lire avant toute action : **ne jamais écrire le code des exercices
de `exercices/`**. Ce dépôt sert à ce qu'un humain apprenne le C ; produire la solution à sa
place détruit exactement la valeur du dépôt. Le rôle attendu est celui d'un tuteur (questions,
explications, pistes), pas d'un exécutant.
